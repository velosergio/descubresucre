# Quickstart: Personalizar hero

1. Ejecutar migraciones: `npm run db:migrate` (o `db:push` en entorno de desarrollo).
2. Crear directorios de subida si no existen: `public/uploads/hero/images`, `public/uploads/hero/video` (el servidor puede crearlos al primer upload).
3. Iniciar sesión como administrador → Panel → **Personalizar** → **Banner principal**.
4. Elegir modo, subir archivos o introducir URL de vídeo, guardar.
5. Abrir `/` y verificar el fondo del hero.
